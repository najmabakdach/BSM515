# BSM515 - Nesneye Dayalı Programlama Dilleri

## Proje Konusu
Code Smells ve Yazılım Kalite Metrikleri Üzerindeki Etkileri

## İncelenen Akademik Makale

**Makale Adı:**  
Software Metric Based Impact Analysis of Code Smells – A Large Scale Empirical Study

**Yazarlar:**  
Md. Masudur Rahman, Abdus Satter, Md. Mahbubul Alam Joarder, Kazi Sakib

**Dergi:** Software: Practice and Experience

**Yayın Yılı:** 2025

**DOI:** 10.1002/spe.3405

## Projenin Amacı

Bu projenin amacı, nesneye dayalı yazılım sistemlerinde
ortaya çıkan Code Smell (Kod Kokusu) türlerini incelemek
ve bu türlerin yazılım kalite metrikleriyle ilişkisini
akademik bir çalışma üzerinden değerlendirmektir.

## Proje Kapsamı

- Code Smell kavramının açıklanması
- Makalenin amacı ve araştırma sorularının incelenmesi
- Kullanılan araştırma yönteminin analiz edilmesi
- Yazılım kalite metriklerinin değerlendirilmesi
- Bulguların nesneye dayalı programlama ile ilişkilendirilmesi
- En az üç temel akademik kaynağın incelenmesi
- Kişisel değerlendirme ve geliştirme önerileri
