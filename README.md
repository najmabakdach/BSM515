BSM515 – Nesneye Dayalı Programlama Dilleri

Proje Konusu

Code Smells ve Yazılım Kalite Metrikleri Arasındaki İlişkilerin Analizi

İncelenen Akademik Makale

Makale Adı:
Software Metric Based Impact Analysis of Code Smells – A Large Scale Empirical Study

Yazarlar:
Md. Masudur Rahman, Abdus Satter, Md. Mahbubul Alam Joarder, Kazi Sakib

Dergi: Software: Practice and Experience

Yayın Yılı: 2025

DOI: 10.1002/spe.3405

Projenin Amacı

Bu projenin amacı, nesneye dayalı yazılım sistemlerinde ortaya çıkan kod kokularını (Code Smells) incelemek ve bu kod kokularının yazılımın iç kalite metrikleriyle ilişkilerini akademik bir çalışma üzerinden değerlendirmektir.

Proje kapsamında kod kokularının tespit edilmesi, etki düzeylerinin belirlenmesi ve yazılım bakım süreçlerinde önceliklendirilmesi konuları ele alınmaktadır.

Proje Kapsamı

* Code Smell kavramının ve türlerinin açıklanması
* Makalenin amacı ve araştırma sorularının incelenmesi
* Araştırma yönteminin ve kullanılan teknolojilerin analiz edilmesi
* Yazılımın iç kalite metriklerinin değerlendirilmesi
* Kod kokuları ile yazılım metrikleri arasındaki istatistiksel ilişkilerin incelenmesi
* Kod kokularının etki puanlarının (Impact Scores) değerlendirilmesi
* Kod kokularının görülme sıklıklarının analiz edilmesi
* Bulguların nesneye dayalı programlama ilkeleriyle ilişkilendirilmesi
* İlgili akademik literatürün incelenmesi
* Araştırmanın güçlü yönlerinin ve sınırlılıklarının değerlendirilmesi
* Kişisel akademik değerlendirme ve geliştirme önerilerinin sunulması

Araştırmada Kullanılan Yöntemler ve Teknolojiler

* Programlama Dili: Java
* Kod Kokusu Tespit Aracı: DÉCOR
* Yazılım Metrik Analiz Aracı: Understand
* Veri Hazırlama: Python ve Bash
* İstatistiksel Analiz: Spearman Sıra Korelasyonu
* Değerlendirme: Impact Score, Quartiles ve One-tailed t-test

İncelenen Araştırmanın Kapsamı

* 35 açık kaynaklı Java yazılım sistemi
* 13 farklı kod kokusu
* 25 iç yazılım metriği
* 325 korelasyon katsayısı
* Kod kokularının etki düzeylerinin ve görülme sıklıklarının karşılaştırılması
